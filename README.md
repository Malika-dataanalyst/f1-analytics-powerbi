# 🏎️ Formula 1 Analytics — Power BI

An interactive Formula 1 analytics project built with **Power BI**, using historical Formula 1 data to explore drivers, constructors, races, and championship performance.

## 📊 Dashboard

The Power BI dashboard is divided into four main sections:

### 🏁 Overview

Provides a high-level view of Formula 1 history, including key statistics and overall championship information.

![Overview Dashboard](Screenshots/overview.png)

### 🏆 Constructors

Analyzes constructor performance across Formula 1 history, including championship performance, points, and race results.

![Constructors Dashboard](Screenshots/constructors.png)

### 👤 Drivers

Explores driver performance, championships, race wins, and points throughout Formula 1 history.

![Drivers Dashboard](creenshots/drivers.png)

### 🌍 Races

Analyzes the history of Formula 1 races and circuits, including race distribution across countries and other race-related statistics.

![Races Dashboard](Screenshots/races.png)

## 🛠️ Tools & Technologies

* **Power BI** — Data visualization and dashboard development
* **DAX** — Measures and analytical calculations
* **SQL Server / SSMS** — Data preparation and analysis
* **CSV** — Source data

## 🔍 Analysis Areas

The project explores questions such as:

* Which constructors have performed best throughout F1 history?
* Which drivers have achieved the most championships?
* Which drivers have the most race wins?
* How has driver performance evolved over time?
* Which countries have hosted the most Formula 1 races?
* How are points and race results distributed across drivers and constructors?

## 📌 Dataset

The project uses historical Formula 1 data covering multiple seasons, drivers, constructors, circuits, races, qualifying sessions, results, standings, and other race-related information.

## 🎯 Project Goal

The goal of this project is to transform raw Formula 1 data into an interactive analytical dashboard and demonstrate practical skills in **data cleaning, data modeling, DAX, SQL, and data visualization**.
